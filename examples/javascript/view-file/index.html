Download a file by path using filesDownload and display its browser fileBlob. This example supports UTF-8 .txt files and PNG or JPEG images. The format is determined from the downloaded file name.

Use an access token with the files.content.read scope. For testing, generate one in the App Console. Paste the token here; it is kept only in memory. Paths start with / and are relative to your app's access root. You can also enter a file ID, such as id:FILE_ID.

This example downloads the entire file into memory before displaying it. Use small files; this is not a universal document viewer.
